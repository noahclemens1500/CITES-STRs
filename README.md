# CITES STR Marker Database

Searchable database of tetranucleotide STR markers and PCR primers for CITES-listed genera,
predicted in silico from public NCBI genome assemblies.

**Open the database:** see the GitHub Pages link in the "About" section of this repository.

- Search by genus, family, order or species (scientific names)
- Filter by chromosome, call rate, number of alleles, gene diversity, amplicon length, primer Tm / GC,
  motif, multiplex pool and quality flags
- Download filtered markers (CSV/TSV) and primers (FASTA)

All markers are computational predictions. PCR performance, stutter and population variability
must be validated in the laboratory before forensic use.

This repository is generated automatically by the CITES STR pipeline (`website.sh publish`);
manual changes are overwritten on the next update.
